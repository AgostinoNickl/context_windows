# Simple copy-text microsite

This is a tiny GitHub Pages site with:
- plain text
- one clickable link-style button
- copy-to-clipboard behavior

## How to use

1. Edit `index.html`.
2. Replace the sentence inside:

   `<p id="text-to-copy">...</p>`

3. Upload the file to a GitHub repository.
4. Enable GitHub Pages from the repository settings.
